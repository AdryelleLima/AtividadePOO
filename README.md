# 🚀 Exercícios de Lógica de Programação e Estruturas de Repetição em Java

Este repositório contém um conjunto de exercícios práticos desenvolvidos em **Java**, focando em estruturas condicionais, laços de repetição, funções/métodos e organização de código com menu interativo.

> 🎓 **Atividades baseadas em exercícios acadêmicos (Senac / Projetos de Aprendizado)**

---

## 📌 Funcionalidades e Algoritmos Integrados

O programa conta com um menu interativo no console que permite ao usuário executar 3 algoritmos diferentes:

### 1. 💵 Sistema de Aumento de Salário
* **Descrição:** Converte uma lógica original em Pascal para Java. Calcula o reajuste salarial de colaboradores com base em faixas de valor e exibe o novo salário juntamente com o percentual de aumento aplicado.
* **Métricas calculadas:**
  * Salário Base
  * Valor do Aumento (fixado por faixa salarial)
  * Percentual de Aumento equivalente
  * Novo Salário final

### 2. 📊 Menor e Maior Valor de um Conjunto
* **Descrição:** Lê uma sequência indeterminada de números inteiros positivos. O algoritmo determina dinamicamente o **maior** e o **menor** número digitado.
* **Condição de parada:** A inserção de dados encerra ao digitar `0` (zero), que não é considerado nos cálculos.

### 3. 👥 Estatísticas do Grupo (Idade e Sexo)
* **Descrição:** Realiza a leitura do sexo (`M` / `F`) e idade de um grupo indeterminado de pessoas.
* **Métricas calculadas:**
  * Média geral de idade do grupo
  * Percentual de pessoas do sexo masculino e feminino
  * Maior idade entre os homens registrados
  * Menor idade entre as mulheres registradas
* **Condição de parada:** Finaliza a leitura quando o sexo informado for igual a `'N'` (ou `'n'`).
